# Rumen Microbiome and Methane Mitigation Meta-Analysis

**Bioinformatics | Microbial Ecology | R Programming | Statistical Modeling**

## Project Overview

This repository documents an ongoing M.S. thesis research project at Auburn University investigating how methane mitigation strategies influence the cattle rumen microbiome.

The project integrates publicly available 16S rRNA amplicon sequencing datasets from multiple studies to evaluate microbial diversity, community composition, and treatment-associated changes.

The research combines microbiome bioinformatics, metadata harmonization, statistical programming, and meta-analysis to investigate relationships between methane mitigation interventions and rumen microbial communities.

## Research Objectives

1. Evaluate changes in rumen microbial alpha diversity associated with methane mitigation strategies.
2. Investigate treatment-associated differences in microbial community composition and beta diversity.
3. Compare microbiome responses across different methane mitigation interventions.
4. Estimate treatment effects using statistical modeling and meta-analytic approaches.

## Technical Skills and Methods

**Bioinformatics**
- 16S rRNA amplicon sequencing analysis
- QIIME 2 workflows
- Microbiome diversity analysis
- Bray–Curtis dissimilarity and principal coordinates analysis (PCoA)
- Integration of sequencing-derived results with study metadata
