
# R Analysis Scripts

This directory contains statistical analysis workflows developed for the rumen microbiome and methane mitigation meta-analysis.

## Analysis Categories

- Metadata processing and harmonization
- Alpha diversity analysis
- Beta diversity analysis
- Mixed-effects statistical modeling
- Meta-analysis and effect size estimation
- Scientific visualization

## Software

R and RStudio

Key R packages:
- dplyr
- tidyr
- ggplot2
- vegan
- lme4
- lmerTest
- metafor
- readxl

## Status

Research workflows are currently being organized and validated for reproducibility.
